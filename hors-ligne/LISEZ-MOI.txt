ETS BARRY FACTURATION — VERSION SANS INTERNET
=============================================

Cette version est faite pour Microsoft Edge, déjà installé sur Windows 10.

INSTALLER (une seule fois)
1. Copiez le dossier « Ets-Barry-Facturation » sur l'ordinateur,
   par exemple dans « Documents ». Ne le laissez pas sur la clé USB.
   (Si vous avez reçu un zip : clic droit dessus, « Extraire tout ».)
2. Astuce : clic droit sur « Ouvrir Facturation » > « Envoyer vers »
   > « Bureau (créer un raccourci) ».

OUVRIR L'APPLICATION (chaque fois)
- Double-cliquez sur « Ouvrir Facturation » (pas sur le fichier .html).
  Edge s'ouvre sur la facturation après 2 secondes.
- La première fois, Windows peut afficher « Windows a protégé votre
  ordinateur » : cliquez sur « Informations complémentaires »,
  puis « Exécuter quand même ».
- Après le premier lancement, le programme démarre tout seul à chaque
  allumage de l'ordinateur. Les favoris Edge vers la facturation
  (http://localhost:8765/) marchent alors aussi.
- Si Edge affiche « Vérifiez votre connexion Internet » ou « Impossible
  d'accéder à cette page » : fermez Edge et double-cliquez sur
  « Ouvrir Facturation ». Il n'y a pas besoin d'internet.
- Si une fenêtre noire affiche « ERREUR », prenez-la en photo.
- Si un cadre rouge « Attention : les factures ne seront pas gardées »
  apparaît, c'est que la page a été ouverte autrement : fermez-la et
  passez par « Ouvrir Facturation ».

OÙ SONT GARDÉES LES FACTURES
- Dans le fichier « donnees-factures.json », dans le dossier de
  l'application. Elles restent quand on ferme Edge ou l'ordinateur.
- Une copie de chaque jour est rangée dans le dossier « sauvegardes ».
- Ne supprimez pas ces fichiers. Pour garder une copie ailleurs,
  copiez tout le dossier sur une clé USB de temps en temps.

AVOIR LA FACTURE EN PDF (avec Edge)
1. Après « Enregistrer », cliquez sur « Imprimer / Enregistrer en PDF »
   dans le cadre vert (ou sur « Imprimer » dans l'Historique).
2. Dans la fenêtre d'impression d'Edge :
   - Imprimante : « Microsoft Print to PDF »
   - En-têtes et pieds de page : « Désactivé »
3. Cliquez sur « Imprimer », choisissez le dossier et le nom du fichier,
   puis « Enregistrer ». Le PDF est prêt.
- Pour imprimer sur papier, choisissez votre imprimante à l'étape 2.

SAUVEGARDE ET RESTAURATION
- Historique > « Sauvegarder l'historique (fichier) » crée un fichier .json.
- Historique > « Restaurer » remet les factures d'un fichier .json,
  sans doublons. Cela sert aussi à passer d'un ordinateur à un autre.

Cette version est séparée du site en ligne : ce qui est fait ici
n'apparaît pas sur ets-barry-facturation.vercel.app, et inversement.
